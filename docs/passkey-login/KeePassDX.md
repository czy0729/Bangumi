# KeePassDX食用方式
## 安装
[官网](https://www.keepassdx.com/)提供了三种方式：

[![F-Droid](https://img.shields.io/badge/F--Droid-KeepassDX-4CAF50?style=for-the-badge&logo=f-droid&logoColor=white)](https://f-droid.org/packages/com.kunzisoft.keepass.libre)
[![Google Play](https://img.shields.io/badge/Google_Play-KeepassDX-4CAF50?logo=googleplay&logoColor=white&style=for-the-badge)](https://play.google.com/store/apps/details?id=com.kunzisoft.keepass.free)
[![GitHub](https://img.shields.io/github/v/release/Kunzisoft/KeePassDX?logo=github&label=Github&style=for-the-badge&color=4CAF50)](https://github.com/Kunzisoft/KeePassDX/releases/latest)

你可以任选一个安装途径。
## 创建密码库
1. 打开软件，点击创建新密码库
![kpdx-1](images/kpdx-1.png)
2. 选择保存位置，点击保存。
![kpdx-2](images/kpdx-2.png)
3. 设置密码，点击确定。
![kpdx-3](images/kpdx-3.png)
4. 至此，完成密码库的创建。
![kpdx-4](images/kpdx-4.png)
## 设置为系统默认首选服务
1. 点击左上角菜单
![kpdx-4](images/kpdx-4.png)
2. 点击`设置`
![kpdx-5](images/kpdx-5.png)
3. 点击`表单填充`
![kpdx-6](images/kpdx-6.png)
4. 开启`凭据提供程序服务`
![kpdx-7](images/kpdx-7.png)
5. 选择KeePassDX
![kpdx-8](images/kpdx-8.png)
6. 至此默认服务设置完成
## 注册Passkey
1. 进入[bangumi官网](https://bgm.tv)并登录
![bgm-1](images/bgm-1.png)
2. 进入[Passkey管理页面](https://bgm.tv/settings/passkeys)，点击添加Passkey
![bgm-2](images/bgm-2.png)
3. 输入密码点击确定
![bgm-3](images/bgm-3.png)
4. 点击继续
![bgm-4kpdx](images/bgm-4kpdx.png)
5. 完成用户验证，后跳转到应用界面
![bgm-5kpdx](images/bgm-5kpdx.png)
6. 点击右下角`+`号
![kpdx-9](images/kpdx-9.png)
7. 点击添加条目
![kpdx-10](images/kpdx-10.png)
8. 点击右下角✅完成
![kpdx-11](images/kpdx-11.png)
9. 至此注册passkey完成
## 使用Passkey
1. 首次使用需要授权特权应用，点击左上角菜单。
![kpdx-4](images/kpdx-4.png)
2. 点击`设置`
![kpdx-5](images/kpdx-5.png)
3. 点击`表单填充`
![kpdx-6](images/kpdx-6.png)
4. 点击`通行密钥设置`
![kpdx-12](images/kpdx-12.png)
5. 点击`特权应用`
![kpdx-13](images/kpdx-13.png)
6. 点亮`com.czy0729.bangumi`，并点击确定
![kpdx-14](images/kpdx-14.png)
7. 进入app登录界面，点击passkey登录
![app-1](images/app-1.png)
8. 系统弹出窗口，点击继续
![app-2kpdx](images/app-2kpdx.png)
9. 完成用户验证
![app-3kpdx](images/app-3kpdx.png)
10. 完成登录
![app-4](images/app-4.png)
